# VLM 学习项目说明（新手快速上手指南）

> 本项目是一套用**最小可运行代码**演示「视觉 / 视觉-语言模型」经典方法的**教学示例**，
> 覆盖两大主题：**自监督预训练**（CLIP / DINO / MAE / MoCo）与**参数高效微调**（Adapter / Linear Probing / Prompt Tuning）。
>
> 每个 `.py` 文件都是一个**独立**的方法示例，可以单独运行，彼此之间没有依赖关系。
> 所有代码都已加上详细中文注释，配合本文档阅读即可快速理解。

---

## 一、这个项目是干什么的？

简单说：**教你如何用「预训练大模型 + 少量数据」完成图像相关任务**，以及这些大模型是**怎么被训练出来的**。

它分成两个阶段（这也是当今深度学习的通用范式）：

1. **预训练（Pre-training）**：在海量数据上，用「自监督」的方式让模型学会通用的图像 / 图文表示。
   - 对应文件：`CLIP.py`、`DINO.py`、`MAE.py`、`moco.py`
   - 关键词：**不需要人工标签**（或只需要很弱的标签）。
2. **微调 / 下游适配（Fine-tuning）**：把预训练好的模型用到具体任务（如图像分类）上。
   - 对应文件：`linear-probing.py`、`adapter.py`、`prompt-tuning.py`
   - 关键词：**冻结大部分参数，只训练很少一部分**，省算力、防过拟合。

## 三、公共基础：它们都用到了什么？

在读具体文件前，先搞懂这几个反复出现的「零件」：

| 零件 | 作用 | 小白理解 |
|------|------|----------|
| **ViT** (`vit_small_patch16_224`) | 图像编码器 | 把图片切成 16×16 的小块（patch），当成「词序列」用 Transformer 处理 |
| **BERT** (`bert-base-uncased`) | 文本编码器 | 把一句话变成向量，取 `[CLS]` 位置作为整句代表 |
| **CIFAR10** | 数据集 | 10 类彩色小图（飞机、汽车、鸟…），常用于教学 |
| **DataLoader** | 数据加载器 | 自动把数据分成一个个 batch（批），并打乱 |
| **patch / token** | 基本单元 | ViT 里一张 224×224 图 → 14×14=196 个 patch，再加 1 个 `[CLS]` → 197 个 token |
| **`requires_grad`** | 是否训练开关 | `False`=冻结不训练，`True`=参与训练 |

**关于 ViT 的输入输出形状**（贯穿全项目，务必记住）：

```
图片         (B, 3, 224, 224)     B=batch大小, 3=RGB通道
 → 切patch   (B, 196, 384)        196个patch, 每个384维(vit_small)
 → 加[CLS]   (B, 197, 384)
 → 过Blocks  (B, 197, 384)        12层Transformer
 → 取[CLS]   (B, 384)             整张图的特征向量
 → 分类头    (B, 类别数)
```

## 四、逐个文件讲解

### 1. `CLIP.py` —— 图文对比学习（有监督 / 弱监督）

**要解决的问题**：让模型学会「图片」和「描述它的文字」之间的对应关系。

**结构**：
- `ViT`：图像编码器，图片 → 512 维向量
- `TextEncoder`：文本编码器（BERT），文字 → 768 维向量
- `CLIP`：把两者维度对齐（用可学习矩阵 `W_i`、`W_t`），再算相似度

**核心逻辑（最重要的一段）**：
```
一个 batch 有 B 张图 + B 段文字
相似度矩阵 logits = 图像特征 @ 文本特征.T   # 形状 (B, B)
logits[i][j] = 第i张图 与 第j段文字 的匹配分数
正确答案在对角线：第i张图 ↔ 第i段文字
→ 用交叉熵，让对角线分数最高，其余（负样本）最低
```
损失是**对称**的：`loss_i`（以图找文）+ `loss_t`（以文找图），取平均。

**运行**：`python CLIP.py`（需先准备好 `./bert-base-uncased/`）

---

### 2. `DINO.py` —— 自监督蒸馏（无标签）

**要解决的问题**：完全不用标签，让模型学会图像表示。

**核心思想：学生-教师（Student-Teacher）**
- **学生网络 `gs`**：正常用梯度训练
- **教师网络 `gt`**：**不用梯度**，而是「动量」缓慢拷贝学生的参数（`gt = l*gt + (1-l)*gs`），相当于学生的平滑版
- 同一张图做两次增强 → 让学生输出**去逼近**教师输出

**两个防崩溃设计**：
- **centering（中心化，变量 `C`）**：减去一个中心，防止所有输出都塌到同一个点
- **sharpening（锐化，温度 `tps`/`tpt`）**：教师用更低温度让输出更「尖锐」

**关键函数**：`H(t, s, C, tps, tpt)` —— 交叉熵损失，让学生 `s` 逼近教师 `t`。

**运行**：`python DINO.py`

---

### 3. `MAE.py` —— 掩码自编码器（无标签）

**要解决的问题**：让模型通过「补全被遮住的部分」来理解图像。

**核心流程**：
```
图片 → 切196个patch → 随机遮住75%(147个) → 编码器 → 解码器 → 重建被遮的patch
损失 = 重建的patch 与 原图被遮patch 的均方误差(MSE)
```

**关键类 / 函数**：
- `MAE.forward()`：完成切块、随机遮罩（`torch.randperm` 打乱取下标）、编码、解码
- `mse_loss()`：**只在被遮住的位置**用 `torch.gather` 取出 patch 计算损失

**运行**：`python MAE.py`（会打印一个重建损失值）

---

### 4. `moco.py` —— 动量对比学习（无标签）

**要解决的问题**：对比学习需要**大量负样本**，但大 batch 太耗显存。

**核心思想**：
- **查询编码器 `f_q`**：用梯度训练
- **键编码器 `f_k`**：动量更新（`f_k = m*f_k + (1-m)*f_q`），保持稳定
- **队列 `queue`**：维护 K=4096 个历史特征当负样本，无需大 batch

**关键函数**：`info_nce_loss(q, k, queue)` —— InfoNCE 对比损失：
```
正样本：同一张图的两个视图 (q, k) → 应该相似
负样本：队列里的历史特征     → 应该不相似
正确答案永远是第0列 → 标签全为0 → 交叉熵
```

> ⚠️ 注意：`info_nce_loss` 里用到的 `N`、`C` 是**模块级全局变量**（在函数下方定义），阅读时别困惑。

**运行**：`python moco.py`

---

### 5. `linear-probing.py` —— 线性探测 vs 全量微调

**要解决的问题**：拿到预训练 ViT 后，最省事的用法是什么？

**两个对比类**：
| 类 | 训练哪些参数 | 特点 |
|----|-------------|------|
| `FineTuning` | **全部** ViT 参数 | 效果可能更好，但成本高、易过拟合 |
| `LinearProbing` | **只训练新分类头**（ViT 全冻结） | 极省算力，常用来评估特征质量 |

在 `main()` 里切换这两行即可对比：
```python
model = LinearProbing(num_classes=10)
# model = FineTuning(num_classes=10)
```

**运行**：`python linear-probing.py`

---

### 6. `adapter.py` —— 适配器微调

**要解决的问题**：比 Linear Probing 更强一点，但又不想全量微调。

**核心思想**：冻结整个 ViT，在**每个 Transformer Block 里并行插入一个很小的 `AdaptMLP`**（降维→ReLU→升维），只训练这些小模块 + 分类头。

**前向流程（`Adapter.forward`）**：手动拆解了 ViT 的每一层，在每个 Block 里做：
```
x = 原MLP输出 + Adapter输出   # Adapter 只学一个「修正量」
```

> ⚠️ **新手避坑**：代码里 `self.adapt_mlps = []` 用的是**普通 Python list**，
> 而不是 `nn.ModuleList()`。这会导致这些 Adapter 的参数**不会被 PyTorch 注册**，
> 优化器可能拿不到它们（训练不到）。若要真正训练，应改为 `nn.ModuleList()`。
> 当前代码用于**理解结构**是没问题的。

**运行**：`python adapter.py`

---

### 7. `prompt-tuning.py` —— 视觉提示微调（VPT）

**要解决的问题**：借鉴 NLP 的 prompt 思想，用极少参数适配新任务。

**核心思想**：冻结 ViT，只往输入序列里插入少量**可学习的「提示 token」**，只训练这些 token + 分类头。

**两种模式**：
- `shallow`（浅层）：只在**输入层**拼接一次提示 token → 序列从 `(B,197,384)` 变 `(B,207,384)`
- `deep`（深层）：**每个 Block** 都重新覆写提示 token，表达能力更强（`main()` 默认用这个）

**运行**：`python prompt-tuning.py`

## 五、方法总览（一张表看懂区别）

| 文件 | 方法 | 阶段 | 是否用标签 | 训练什么 |
|------|------|------|-----------|----------|
| `CLIP.py` | 图文对比 | 预训练 | 图文配对 | 图像+文本编码器+对齐矩阵 |
| `DINO.py` | 自蒸馏 | 预训练 | ❌ 无 | 学生网络（教师动量更新） |
| `MAE.py` | 掩码重建 | 预训练 | ❌ 无 | 编码器+解码器 |
| `moco.py` | 动量对比 | 预训练 | ❌ 无 | 查询编码器（键动量更新） |
| `linear-probing.py` | 线性探测/微调 | 下游 | ✅ 有 | 只训分类头 / 或全部 |
| `adapter.py` | 适配器 | 下游 | ✅ 有 | 小型 Adapter + 分类头 |
| `prompt-tuning.py` | 提示微调 | 下游 | ✅ 有 | 提示 token + 分类头 |

**记忆口诀**：
- 预训练四兄弟：**CLIP 对齐图文，DINO 师生蒸馏，MAE 遮图重建，MoCo 队列对比**。
- 微调三兄弟：**Linear 只换头，Adapter 插小瓶，Prompt 加提示**（都是「冻结主干，只训一点点」）。

## 六、环境准备与运行

### 1. 依赖库
```bash
pip install torch torchvision timm transformers numpy
```

### 2. 数据集
CIFAR10 会在首次运行时**自动下载**到 `./cifar10/`（需要联网）。

### 3. CLIP 额外准备
`CLIP.py` 需要本地 BERT 模型，放到 `./bert-base-uncased/` 目录（含 `config.json`、权重、词表等）。
若暂时没有，可先运行其它 6 个文件。

### 4. 运行任意示例
```bash
python MAE.py            # 最快看到效果，无需联网下 BERT
python DINO.py
python moco.py
python linear-probing.py
python adapter.py
python prompt-tuning.py
python CLIP.py           # 需准备好 BERT
```

### 5. 关于「运行结果」的重要说明
> 这些文件是**教学演示**，主要展示**前向传播 + 损失计算**的完整逻辑。
> - `MAE.py` / `linear-probing.py` / `adapter.py` / `prompt-tuning.py` / `CLIP.py`：
>   会遍历数据集打印 loss，但**部分没有写完整的反向传播训练循环**（DINO、MoCo 有完整训练循环）。
> - 首次运行会**下载预训练权重和数据集**，需要联网且耗时较长；ViT/BERT 对显存有一定要求，
>   如果显存不足，可把 `batch_size` 调小。

## 七、给新手的学习路线建议

1. **先跑通最简单的**：从 `MAE.py` 入手（不依赖 BERT，逻辑自洽），理解「切 patch → 遮罩 → 重建」。
2. **理解微调三兄弟**：`linear-probing.py` → `adapter.py` → `prompt-tuning.py`，
   重点体会「冻结主干 + 只训练少量参数」这个共同思想。
3. **再看自监督预训练**：`moco.py`（对比学习）→ `DINO.py`（师生蒸馏）→ `CLIP.py`（图文对齐）。
4. **对照注释读代码**：每个文件顶部都有「核心思想（小白版）」的文档字符串，先读它再看 `forward`。
5. **动手改**：试着改 `batch_size`、`mask_ratio`、`mode='shallow'/'deep'` 等参数，观察输出变化。

## 八、常见问题（FAQ）

**Q：运行报错找不到 `bert-base-uncased`？**
A：这是 `CLIP.py` 专用的，需要先下载 BERT 模型放到该目录。可先跳过 CLIP，运行其它文件。

**Q：为什么 loss 打印出来不下降 / 没有训练效果？**
A：部分示例只演示了前向传播和 loss 计算，没有完整的训练循环（没有 `optimizer.step()`），
这是**教学用途**，目的是让你看懂模型结构和数据流，而非训练出可用模型。

**Q：`adapter.py` 里的 Adapter 真的能训练吗？**
A：见上文「新手避坑」——当前用的是普通 list，参数未被注册；理解结构没问题，真要训练需改成 `nn.ModuleList()`。

**Q：显存不够 / 太慢？**
A：调小 `batch_size`；ViT-small + CIFAR10 已是最小配置，若仍吃力可只跑 `MAE.py`（可用随机张量，无需真实数据）。
